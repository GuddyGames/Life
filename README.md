# Life: Open World

> The Sims meets GTA: San Andreas — a living Nigerian open-world life simulation.

## Foundation v0.1

The first repository milestone establishes the Next.js + TypeScript foundation and a responsive game-dashboard prototype for the Mainland starting experience.

### Current foundation
- Next.js + React + TypeScript
- Mainland districts: Yaba, Surulere, Ikeja, Mushin
- Character starter profile
- Nigerian naira economy concept
- Daily needs UI
- Starter hustles
- Responsive mobile/desktop layout

## Development direction

1. Character Creator / CAS
2. Needs + emotions engine
3. Playable 3D Mainland block
4. NPC interaction system
5. Jobs and missions
6. Housing and inventory
7. Vehicles and larger world
8. Multiplayer after the single-player simulation is fun

## Principle

Build a small piece of Lagos that already feels alive before expanding the world.
